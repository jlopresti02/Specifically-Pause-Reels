# Fonts

The published reels use two free Google Fonts. Download the TTFs and drop them here:

- `Bangers-Regular.ttf` (headlines): https://fonts.google.com/specimen/Bangers
- `PermanentMarker-Regular.ttf` (taunts, bubbles, doodles): https://fonts.google.com/specimen/Permanent+Marker

Without them the renderer falls back to a system bold font, so it still runs, but the look is plainer.
